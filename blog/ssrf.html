SSRF Explained & How to Prevent It in Node.js

🔍 What is SSRF?

SSRF (Server-Side Request Forgery) is a vulnerability where an attacker tricks your server into making requests to internal or external systems. It bypasses firewalls because your server itself becomes the attacker. 

// Vulnerable Node.js example
app.get('/fetch', async (req, res) => {
  const url = req.query.url;
  const data = await axios.get(url); // ❌ No validation means SSRF risk
  res.send(data);
});

🚨 Why SSRF Is Dangerous

  • Access to internal microservices
  • Access to cloud metadata services (AWS, GCP, Azure)
  • Bypassing firewalls and network ACLs
  • Leaking environment secrets
  • Pivoting deeper into private networks
